# AntiCorrupt — демонстрационный сайт

## Запуск на MacBook (VS Code)
1. Распакуйте `AntiCorrupt.zip`.
2. Откройте папку `AntiCorrupt` в VS Code.
3. Откройте `index.html` в браузере или запустите через расширение **Live Server**.
4. Для теста отправьте пробное обращение. Оно сохранится в `localStorage` этого браузера.
5. Внизу страницы откройте «Панель управления». Демо-пароль: `2468`.

## Что работает
- Русский и узбекский интерфейс.
- Форма демонстрационного обращения с проверкой обязательных полей.
- Генерация номера обращения.
- Проверка статуса по номеру.
- Локальная статистика.
- Демо-админ-панель: просмотр обращений, смена статуса, экспорт CSV.

## Важно перед реальным запуском
Это frontend-прототип, а не действующий канал подачи жалоб. Данные никуда не отправляются и доступны только в том же браузере. Пароль администратора находится в JavaScript и не обеспечивает защиту. Для реального сервиса нужны серверная часть, защищённая база данных, серверная авторизация и роли доступа, HTTPS, политика конфиденциальности, правила хранения/удаления данных, защита от спама и юридическая проверка процесса. Не собирайте чувствительные персональные данные и не обещайте анонимность, пока она не обеспечена технически и организационно. Не публикуйте непроверенные обвинения.
